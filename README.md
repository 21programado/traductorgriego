# Griego Bíblico
Traductor y guía gramatical de griego bíblico (koiné) al español.

## Cómo obtener tu API Key (gratis)

1. Entrá a https://aistudio.google.com e iniciá sesión con tu cuenta de Google.
2. Buscá la opción **Get API key** (Obtener clave de API) en el menú.
3. Tocá **Create API key** (Crear clave de API) y copiala.
4. Abrí el programa y pegala cuando te la pida. Se guarda solo en tu computadora.

Cada usuario necesita su propia clave. No la compartas con nadie.

## Uso de la app

1. Pegá o escribí el texto griego.
2. Elegí **Completo** o **Breve**.
3. Tocá **Traducir**.
4. ## Si Windows bloquea el programa (es esperable y requiere confianza de tu parte en el desarrollador de la aplicación):

Al abrir el programa por primera vez, Windows puede mostrar el aviso
**"Windows protegió su PC"**. Es normal: ocurre con cualquier programa
nuevo que no tiene firma digital, y no significa que tenga un virus.

Para abrirlo:

1. Tocá **Más información**.
2. Tocá **Ejecutar de todas formas**.

Solo hace falta la primera vez.

Si el navegador (Chrome o Edge) advierte al descargarlo que el archivo
"no se descarga habitualmente", elegí **Conservar**.

Algunos antivirus pueden marcarlo por error. El código fuente está
completo en este repositorio (`traductor_griego.py`) por si querés revisarlo
o generar el .exe vos mismo.
